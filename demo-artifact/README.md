# BuildFlow demo artifact

A self-contained, clickable version of BuildFlow that runs inside Claude as an artifact, using the artifact's shared database instead of Firebase. Built for showing partners; the real app is the Next.js project in this repo.

- `index.html` — the whole app (React 18 + htm from a CDN)
- `seed.mjs` — demo data loaded into the artifact database (all fictional)

Live: https://claude.ai/artifact/XJA6r6ggyiGegLkuYudDTP (private until shared from its Share menu)
